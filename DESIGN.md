# AdVault Spy — UI Direction v1.3.3

## Reference direction

A compact AI-CRM / analytics workspace inspired by current Dribbble dashboard patterns: dark neutral surfaces, clear KPI hierarchy, restrained accent color, dense but breathable lead cards, and strong primary actions.

Reference inspirations:
- AI CRM Dashboard UI / SaaS Analytics Interface — The Voyage Studio
- SaaS CRM Dashboard UI — Nixtio
- Dark Analytics Dashboard UI — Fatima Masood

These are inspiration references only; the AdVault interface is an original implementation for the extension's prospecting workflow.

## Product hierarchy

1. Scan the current page
2. Show scan metrics
3. Surface advertising intelligence
4. Rank best prospects
5. Explain evidence
6. Generate outreach/pitch
7. Export leads

## Visual system

- Background: near-black #090A0C
- Surfaces: #101216 / #14161B
- Borders: #242832
- Primary text: #F5F7FB
- Muted text: #8B919D
- Accent: soft periwinkle #A1B1FD
- Positive: #67D7A0
- Warning: #F1BD72

## UX rules

- Never make the user choose CSS selectors before scanning.
- Keep the Scan Page action dominant.
- Use numbers and evidence before decorative content.
- Show why a prospect scored well.
- Keep AI copy secondary to verifiable business/ad signals.
